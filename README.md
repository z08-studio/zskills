# ZSkill Lens

A macOS app for visually exploring, reading, and learning from Agent Skills.

Part of Z Studio.

## Direction

ZSkill Lens helps people understand how Skills are written and organized, study
their instructions and supporting resources, and build their own expertise.

The app will bring together Skills from local folders and remote machines over
SSH. Remote sources may include Linux and macOS hosts; the app itself targets
macOS.

## Status

The project repository has been initialized. Detailed features, interface design,
and implementation choices will be discussed next. Application code has not yet
